## File Formats

| Format | Purpose |
|--------|---------|
| `.f3d` | Native Fusion 360 archive (open in Fusion 360) |
| `.step` | Universal CAD exchange, for other CAD software |
| `.stl` | 3D printing |
| `.pdf` | Technical drawings |

## How to Open the Files

1. Install [Autodesk Fusion 360](https://www.autodesk.com/products/fusion-360) (free personal-use license available for eligible users).
2. Download or clone this repo:
   ```bash
   git clone https://github.com/LegendSeyi/[repo-name].git
   ```
3. In Fusion 360, go to **File → Open → Open from my computer** and select the `.f3d` file.
4. No Fusion 360? Use the `.step` file in any CAD tool, or view the renders in each project's `renders/` folder.
